# Cashflow — marketing page

Marketing landing page for **Cashflow**, a mobile app that reads the SMS receipts generated by
Orange Money and MTN Mobile Money transactions, classifies each transaction by category, and
produces a monthly report of total spending per category so users can see where their money goes.

## Contents

| Path | What it is |
| --- | --- |
| `Cashflow Landing.dc.html` | The marketing page. Open it directly in a browser. |
| `support.js` | Runtime required by the page. Keep it next to the HTML file. |
| `_ds/modernist-.../` | Modernist design system: `styles.css` (tokens + components) and its bundle. |
| `assets/app-transactions.jpg` | Screenshot of the app's Transactions screen, used in the hero. |

## How to open

Serve the folder over HTTP (the page loads local files, so `file://` may block them):

```bash
python3 -m http.server 8000
# then open http://localhost:8000/Cashflow%20Landing.dc.html
```

## Page structure

Hero → problem → how it works (3 steps) → monthly report example → features →
poster statement → roadmap → pricing → sign-up form → FAQ → footer.

The sign-up form is front-end only: it switches to a confirmation state on submit and does not
send anything anywhere. Wire it to your own endpoint (email list, WhatsApp, CRM) before launch.

## Roadmap shown on the page

1. **Phase 1 — delivered.** Transaction ledger for Orange Money and MTN MoMo, editable
   categories, search, monthly report.
2. **Phase 2 — in progress.** Per-category budget caps, alerts when a category overruns,
   shareable report export.
3. **Phase 3 — planned.** Multiple numbers, multi-user accounts for small businesses,
   then an English-language version.

## Target markets

Cameroon, Côte d'Ivoire, Senegal, Mali, Burkina Faso, Guinea, DR Congo, Madagascar.

## Privacy claim on the page

The page states that the app reads only the operator SMS already on the device, never asks for a
Mobile Money PIN, and does not upload messages to a server. Keep the app's behaviour in step with
this copy — and with the store listing — before publishing.
